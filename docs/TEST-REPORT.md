## Известные проблемы фазы 2 / что не проверено

1. **Windows/macOS** по-прежнему вживую не проверялись (временные natives сделаны именно ради Windows).
2. Режимы «Скрыть лаунчер» / «Закрыть лаунчер» при запуске игры реализованы, но в интерфейсе вживую не проверялись.
   В режиме «закрыть» игра запускается отсоединённым процессом, временную папку natives убирает уборка при следующем старте лаунчера.
3. Уведомления «нет сети» / «мало места» проверены модульными тестами (классификация, проверка места до загрузки),
   но в UI не имитировались (сеть на тестовой машине не отключали).
4. Имена пользователей / пути данных с не-ASCII символами могут мешать Java 8 + LWJGL 2 на Windows (не проверялось).
5. Окно редактора профиля выше маленького окна (≈730 px) — тело окна прокручивается; кнопки «Сохранить/Отмена» закреплены.
6. Кириллицу в поле ввода автоматический тест набирал через `setxkbmap ru` + `xdotool` — это ограничение средства автоматизации, не лаунчера.
7. `build/icon.icns` собран скриптом из PNG (icp4…ic10) без `iconutil`; на macOS при релизе стоит перепроверить (фаза 5).
8. Удаление неиспользуемых версий/библиотек пока нет (фаза 3).

## Известные проблемы фазы 1 (статус на сейчас)

1. **Windows и macOS не тестировались вживую.** Код учитывает: `javaw.exe`, `jre.bundle/Contents/Home/bin/java`,
   `-XstartOnFirstThread`, разделитель `;`, `%APPDATA%`, симлинки Java runtime (на Windows пропускаются — в Windows-runtime Mojang их нет).
2. ~~Общая игровая папка `instances/default` (падение старых версий на `options.txt` от новых)~~ — **исправлено в фазе 2**: у каждого профиля своя папка.
3. **Linux:** для новых версий на SDL3 (26.x) нужен системный `libEGL` (`libegl1`), иначе «Couldn't find matching GLX visual».
   Надо описать в требованиях / deb-зависимостях (фаза 5).
4. **Linux arm64 / прочие архитектуры:** Mojang runtime нет → Adoptium (код есть, вживую не проверялся);
   у старых версий нет arm64-natives в JSON.
5. Правила `os.version` сверяются с `os.release()` (на macOS это версия ядра Darwin, а не macOS). Затрагивает только
   очень старые правила (`^10\.5\.\d$`).
6. ~~Общая папка natives (блокировка файлов на Windows)~~ — **исправлено в фазе 2**: временная папка на каждый запуск.
7. При каждом запуске ресурсы перепроверяются по SHA1 (~1–3 с на 700 МБ с тёплым кэшем ФС); Java runtime после
   первой проверки сверяется только по размеру.
8. ~~Нет иконки~~ — иконки есть в `build/` (фаза 2); автообновление и подпись — фаза 5.
9. `--no-sandbox` использовался только для запуска Electron на тестовой машине; в код и сборку он не добавлен.
